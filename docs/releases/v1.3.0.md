# DiskLens 1.3.0

[English](#english) · [简体中文](#简体中文)

## English

A local Ubuntu storage explorer, now with a switchable English / Chinese interface and adjustable text size.

### New in 1.3

- **Language & font:** use the sidebar button to choose English or Simplified Chinese, and a base font size from **11 to 18 px** (default 13).
- **Immediate, saved preferences:** pages, table headers, status messages, dialogs and charts follow the selected language and font. Your page, scan directories and window position are kept. Read-only scans restart and pending selections are cleared.
- **Operation protection:** appearance changes wait until cache cleanup, package operations and modal dialogs have finished.
- **Reproducible launch options:** `--language en` / `--language zh_CN` and `--font-size 18` override preferences for one run without saving them.
- **New home:** [broruan/DiskLens](https://github.com/broruan/DiskLens), with separate English and Chinese README files and release sections.

Directory exploration, complete SHA-256 duplicate verification, developer storage insights, app storage profiles, selected cache/log cleanup and protected uninstall previews remain available. Installed package names, descriptions, paths and external package-manager output retain their source language.

### Install or update

Download the DEB matching **both** your Ubuntu release and architecture: **22.04 / 24.04 / 26.04 × amd64 / arm64**.

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

For Ubuntu 24.04 x86_64:

```bash
sudo apt install ./disklens_1.3.0_ubuntu24.04_amd64.deb
disklens
```

Download `SHA256SUMS` beside your package and verify it:

```bash
sha256sum --ignore-missing --check SHA256SUMS
```

### Validation

Thirteen automated test targets cover scanning, package operations, analysis tools, full compiled translation coverage, saved preferences, language switching and font scaling under the production style. Native release jobs test, verify and install each package, then run all seven pages in both languages and selected pages at 18 px. Physical desktop sessions and authorized package removal are separate manual checks.

## 简体中文

面向 Ubuntu 的本地磁盘空间分析工具，现在可以在软件内切换中英文，并调整字体大小。

### 1.3 新功能

- **语言与字体**：点击侧栏入口，选择简体中文或 English，基础字号支持 **11–18 px**，默认 13 px。
- **立即生效并保存**：页面、表头、状态提示、对话框与图表跟随设置变化。保留当前页面、扫描目录和窗口位置；只读扫描重新开始，待处理选择清空。
- **操作保护**：缓存清理、软件包操作和模态窗口结束后才允许切换设置。
- **临时启动选项**：`--language zh_CN` / `--language en` 与 `--font-size 18` 仅覆盖本次运行，不保存到偏好设置。
- **项目新地址**：[broruan/DiskLens](https://github.com/broruan/DiskLens)，中英文 README 与 Release 章节分别展示。

目录分析、完整 SHA-256 重复校验、开发环境识别、软件空间画像、所选缓存日志清理与受保护的卸载预览继续可用。软件包名称、描述、文件路径和外部包管理器输出保留其来源语言。

### 安装或更新

请同时匹配 **Ubuntu 版本和 CPU 架构**：**22.04 / 24.04 / 26.04 × amd64 / arm64**。

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

以 Ubuntu 24.04 x86_64 为例：

```bash
sudo apt install ./disklens_1.3.0_ubuntu24.04_amd64.deb
disklens
```

将校验文件与安装包放在同一目录并验证：

```bash
sha256sum --ignore-missing --check SHA256SUMS
```

### 验证

13 个自动测试目标覆盖扫描、软件包操作、分析工具、完整编译译文、设置持久化，以及正式样式下的语言切换和字号缩放。各原生发布任务测试、检查并安装 DEB，再检查全部七类页面的中英文界面，以及部分页面的 18 px 字号。实体桌面会话与授权卸载需独立手工验证。

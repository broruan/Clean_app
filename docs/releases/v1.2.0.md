# DiskLens 1.2.0

[English](#english) · [简体中文](#简体中文)

## English

Understand what occupies your Ubuntu disk, down to directories, duplicate contents and developer workspaces.

### New in 1.2

- **Directory explorer:** drill into a size-sorted hierarchy or click the current-level allocation chart; compare logical and allocated sizes.
- **Duplicate verification:** size → head/tail sample → complete SHA-256, with changing-file checks and grouped paths.
- **Developer storage:** recognize colcon outputs, ROS recordings, point clouds, pip/npm/ccache caches and Conda environments; inspect evidence, purpose and rebuildability.
- **App storage profile:** inspect associated DEB data paths and Snap/Flatpak namespaces separately from package-size estimates.
- **CSV reports:** export scope, partial-result flags, accounting and paths; prevent overwriting existing scanned inputs.

New analysis tools inspect and export without deleting duplicate files, developer outputs or app data. Selected cache/log cleanup and protected package-removal previews remain available.

### Packages

Six native DEBs: **Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64**. Match both Ubuntu release and architecture.

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

For Ubuntu 24.04 x86_64:

```bash
sudo apt install ./disklens_1.2.0_ubuntu24.04_amd64.deb
disklens
```

Download `SHA256SUMS` beside your package and verify it:

```bash
sha256sum --ignore-missing --check SHA256SUMS
```

### Validation

All six native jobs passed eleven CTest targets, DEB verification, installation, and read-only overview/explorer/duplicates/developer smoke checks. Physical desktop sessions and authorized package removal need separate manual checks. This version's interface is Simplified Chinese.

## 简体中文

从目录、重复内容和开发工作空间，看懂 Ubuntu 磁盘占用。

### 1.2 新功能

- **目录分析**：逐层浏览按大小排序的目录树或点击占用比例图，分别查看逻辑大小与实际占用。
- **重复校验**：大小筛选、头尾采样、完整 SHA-256，复核变化文件并展示分组路径。
- **开发环境**：识别 colcon 产物、ROS 录制、点云、开发缓存与 Conda 环境，展示依据、用途与可重建性。
- **软件画像**：关联已知 DEB 数据目录及 Snap/Flatpak 用户目录，与包体积估算分开展示。
- **CSV 报告**：导出范围、完整性、统计和路径，保护已分析输入不被覆盖。

新增分析功能用于查看和导出，不删除重复文件、开发产物或应用数据。所选缓存日志清理、受保护的软件卸载预览继续可用。

### 安装包

六个原生 DEB：**Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64**。请同时匹配系统版本与架构。

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

以 Ubuntu 24.04 x86_64 为例：

```bash
sudo apt install ./disklens_1.2.0_ubuntu24.04_amd64.deb
disklens
```

将校验文件与安装包放在同一目录并验证：

```bash
sha256sum --ignore-missing --check SHA256SUMS
```

### 验证

六个原生构建任务全部通过 11 个 CTest 目标、DEB 检查、安装和总览、目录、重复、开发页面只读检查。实体桌面会话与授权卸载需独立手工验证。此版本界面为简体中文。

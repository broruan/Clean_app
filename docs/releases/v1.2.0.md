# DiskLens 1.2.0 · 磁盘透镜

Understand what occupies your Ubuntu disk, down to directories, duplicate contents and developer workspaces.

从目录、重复内容和开发工作空间，看懂 Ubuntu 磁盘占用。

## New in 1.2 · 新功能

| Feature / 功能 | What it does / 能力 |
| --- | --- |
| Directory explorer / 目录分析 | Drill into a size-sorted hierarchy or click the current-level allocation chart. Compare logical and allocated bytes. / 逐层浏览目录树或点击占用比例图，分别查看逻辑大小与实际占用。 |
| Duplicate verification / 重复校验 | Size → head/tail sample → complete SHA-256, with changing-file checks and grouped paths. / 大小筛选、头尾采样、完整 SHA-256，复核变化文件并展示分组路径。 |
| Developer storage / 开发环境 | Recognize colcon outputs, ROS recordings, point clouds, pip/npm/ccache caches and Conda environments. Show evidence, purpose and rebuildability. / 识别 colcon 产物、ROS 录制、点云、开发缓存与 Conda 环境，展示依据、用途与可重建性。 |
| App storage profile / 软件画像 | Inspect associated DEB data paths and Snap/Flatpak namespaces separately from package-size estimates. / 将已知 DEB 数据目录及 Snap/Flatpak 用户目录与软件关联，和包体积估算分开展示。 |
| CSV reports / 报告导出 | Export scope, partial-result flags, accounting and paths; prevent overwriting existing scanned inputs. / 导出范围、完整性、统计和路径，保护已分析输入不被覆盖。 |

New analysis tools inspect and export; they do not delete duplicate files, developer outputs or app data. Existing selected cache/log cleanup and protected package-removal previews remain available.

新增分析功能用于查看和导出，不删除重复文件、开发产物或应用数据。已有的所选缓存日志清理、受保护的软件卸载预览继续可用。

## Packages · 安装包

Six native DEBs: **Ubuntu 22.04 / 24.04 / 26.04 × amd64 / arm64**. Match both the Ubuntu release and architecture. / 六个原生 DEB，请同时匹配系统版本与架构。

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

Example / 示例：

```bash
sudo apt install ./disklens_1.2.0_ubuntu24.04_amd64.deb
disklens
```

Download `SHA256SUMS` beside your package and verify it. / 将校验文件与安装包放在同一目录并验证：

```bash
sha256sum --ignore-missing --check SHA256SUMS
```

## Validation · 验证

Eleven automated test targets cover the existing functionality and new analysis modules. Native release jobs build, test, verify and install each package, then exercise the overview, directory, duplicate and developer pages in read-only offscreen mode. Physical desktop sessions and authorized package removal remain separate manual checks.

十一个自动测试目标覆盖原有功能与新增分析模块。各原生发布任务均构建、测试、检查并安装包，再对总览、目录、重复及开发页面执行离屏只读检查。实体桌面会话与授权卸载仍需独立手工验证。

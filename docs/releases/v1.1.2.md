# DiskLens 1.1.2

[English](#english) · [简体中文](#简体中文)

## English

Local disk insight for Ubuntu, with native x86_64 and ARM64 builds.

### What's included

- Original application icon, scalable SVG and desktop icon sizes.
- Separate English and Chinese README files, usage and development guides.
- Native build, test and DEB packaging for Ubuntu 22.04, 24.04 and 26.04 on amd64 and arm64.
- Version-specific runtime dependencies, architecture checks and SHA-256 checksums.
- Disk overview, installed package inventory, protected uninstall preview, large-file scanning and selected user cache/log cleanup.

### Install

Choose the package matching **both** your Ubuntu version and architecture:

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
sudo apt install ./disklens_1.1.2_ubuntu22.04_amd64.deb
disklens
```

The command above is for Ubuntu 22.04 x86_64. ARM64 needs the `arm64` package. `amd64` also covers Intel x86_64 CPUs. Download `SHA256SUMS` beside the DEB and verify it:

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

### Notes

This version's interface is Simplified Chinese. CI covers compilation, automated tests, package installation and a read-only offscreen smoke check. Physical desktop, Wayland and Polkit authorization checks are separate. Cache cleanup permanently deletes confirmed scanned files without using the Trash; review selected paths first.

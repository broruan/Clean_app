# DiskLens 1.1.2 · 磁盘透镜

Local disk insight for Ubuntu, with native x86_64 and ARM64 builds.

面向 Ubuntu 的本地磁盘空间管理工具，提供原生 x86_64 与 ARM64 构建。

## What's included · 更新内容

- A refreshed original application icon, scalable SVG and desktop icon sizes. / 更新自有应用图标，提供 SVG 与多尺寸桌面图标。
- Complete English and Chinese README files, usage and development guides. / 完整中英文 README、使用说明与开发指南。
- Native build, test and DEB packaging jobs for Ubuntu 22.04, 24.04 and 26.04 on amd64 and arm64. / Ubuntu 22.04、24.04、26.04 的 amd64 / arm64 原生构建、测试与 DEB 打包。
- Version-specific runtime dependencies, architecture checks and SHA-256 checksums. / 按系统版本生成运行依赖，校验包架构并提供 SHA-256 校验文件。
- Existing disk overview, installed package inventory, protected uninstall preview, large-file scanning and selected user cache/log cleanup. / 保留磁盘总览、软件库存、受保护的卸载预览、大文件扫描与所选用户缓存/日志清理。

## Install · 安装

Choose the package matching **both** your Ubuntu version and architecture. / 请同时匹配 Ubuntu 版本和 CPU 架构。

```bash
. /etc/os-release
printf 'Ubuntu %s\n' "$VERSION_ID"
dpkg --print-architecture
```

Example for Ubuntu 22.04 x86_64 / Ubuntu 22.04 x86_64 示例：

```bash
sudo apt install ./disklens_1.1.2_ubuntu22.04_amd64.deb
disklens
```

For ARM64, use the `arm64` package. `amd64` also covers Intel x86_64 CPUs. / ARM64 请使用 `arm64` 包；`amd64` 同样适用于 Intel x86_64 处理器。

Download `SHA256SUMS` alongside your DEB, then verify the file you downloaded. / 将 `SHA256SUMS` 与 DEB 放在同一目录，校验已下载文件：

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

## Notes · 说明

The app interface is currently Simplified Chinese; project documentation is bilingual. CI covers compilation, automated tests, package installation and a read-only offscreen smoke check. It does not replace testing on each physical desktop, Wayland session or Polkit authorization flow.

应用界面目前为简体中文，项目文档为中英双语。CI 覆盖编译、自动测试、安装包安装及离屏只读界面检查；不等同于逐台实体桌面、Wayland 会话或 Polkit 授权流程验证。

Cache cleanup permanently deletes confirmed scanned files; it does not use the Trash. Review the selected paths before confirming. / 缓存清理直接删除已确认的扫描文件，不进入回收站；确认前请核对所选路径。
